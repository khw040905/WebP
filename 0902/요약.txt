1. 웹의 기본 개념

* 웹(Web): 여러 컴퓨터에 있는 문서와 정보를 서로 공유하고 볼 수 있도록 만든 서비스
* WWW(World Wide Web): 인터넷을 이용해 정보들이 거미줄처럼 연결된 구조

구성 요소
* 웹 서버: 웹사이트의 HTML, 이미지, 동영상 등의 자료를 저장하고 요청에 응답하는 컴퓨터
* 웹 클라이언트: 사용자가 브라우저를 통해 웹 문서를 요청하고 화면에 보는 역할

2. 인터넷과 웹의 차이

* 인터넷: 여러 컴퓨터를 연결하는 네트워크이며 IP 주소로 컴퓨터를 구분함
* 웹: 인터넷을 기반으로 정보를 제공하는 서비스
* 쉽게 말하면 인터넷은 고속도로, 웹은 그 고속도로를 이용하는 서비스라고 볼 수 있음.

3. 웹 문서와 전자 문서

웹 문서
* 여러 페이지로 나누어 저장
* 하이퍼링크로 서로 연결
* 사용자가 원하는 순서대로 이동 가능

 전자 문서
* 하나의 파일에 내용을 저장
* 작성자가 정한 순서대로 읽음

4. URL의 구조

예시: http://www.oracle.com:80/technetwork/java/index.html
http: 프로토콜
[www.oracle.com](http://www.oracle.com): 서버 주소
80: 포트 번호
/technetwork/java: 경로
index.html: 파일 이름

5. 웹을 선호하는 이유

* HTML 태그를 배우기 쉬움
* HTTP 통신으로 효율적인 서비스 제공
* 서버와 클라이언트가 작업을 나누어 처리 가능

6. 웹 페이지의 3요소

* HTML: 웹페이지의 구조
* CSS: 디자인과 화면 꾸미기
* JavaScript: 사용자와의 상호작용
* HTML = 뼈대 / CSS = 디자인 / JavaScript = 움직임과 기능

7. HTML5의 기능과 의의

주요 기능
웹 폼, 오디오·비디오, 캔버스, SVG, 웹 스토리지, 위치 정보, 웹 소켓, 오프라인 웹 앱 등을 지원함.
의의
* 운영체제나 기기에 대한 의존성을 줄임
* Active-X나 별도의 플러그인이 필요 없음
* 단순 문서 작성뿐 아니라 웹 애플리케이션 개발이 가능해짐
